About this release

UMA shows one versioned release of the Urban Microbiome Database (UMDB): the catalog of public urban microbiome sequencing as it stood when the release was cut, and the analyses STRIGA ran on exactly that catalog.

UMDB

Harvests studies, BioSamples and runs from NCBI SRA, BioSample and BioProject; screens every BioSample for urban evidence (five tiers, with the evidence); validates locations against GeoNames; publishes versioned releases. Its live, unreleased catalog is at aglucaci.github.io/UMDB.

github.com/aglucaci/UMDB

STRIGA

A Nextflow pipeline that tests pre-registered hypotheses on a UMDB catalog, with outside data (World Bank, GeoNames, OpenFlights). It records the SHA-256 of the database it analysed, and a release only bundles results from that exact database.

github.com/aglucaci/STRIGA

UMA

This site. uma build reads one release and writes static files: the findings with their figures and tables, an index of studies and places, and one record file per study. No server, no account.

github.com/aglucaci/UMA
